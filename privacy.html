tumxcc 隱私權政策

最後更新：2026-11-26

取得哪些資料

  • Gmail 寄信權限（gmail.send）：只用來以使用者的名義寄出通知信。tumxcc 不讀取、不搜尋、不刪除使用者的任何信件。
  • 帳號 email（openid、email）：只用來在設定頁顯示目前連結的帳號。

如何使用與保存

  • 授權後取得的權杖（token）加密保存在 tumxcc 的伺服器上，只用於寄出使用者自己設定的通知信。
  • 寄出的信件內容由使用者或其排程產生，tumxcc 不另外保存寄出的信件。
  • 不將任何 Google 使用者資料出售、分享或轉交給第三方，也不用於廣告或訓練 AI 模型。

tumxcc 使用 Google API 取得的資料，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

如何撤銷

  • 在 tumxcc 的「Bot 設定 → Google」按「中斷連結」，伺服器上的權杖會立即刪除。
  • 也可以到 Google 帳戶 → 第三方存取權 移除 tumxcc。

聯絡

有任何問題，請聯絡 tumxcc 的管理員。
